# CFB Career Sim

A college football career in about twenty decisions. Pick your school, take
your gambles with the odds in plain sight, climb the depth chart, and call the
play when the season is on the line.

**Play it:** https://tjkuri.github.io/cfb-career-sim/

## Develop

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # engine, content and UI tests
npm run typecheck
npm run balance    # simulates thousands of careers and prints the draft spread
```

Pushing to `main` typechecks, tests, builds and deploys to GitHub Pages.

How the game works and why it is shaped this way: `docs/REWORK-2026-10.md`.
